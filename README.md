# IBM Data Analyst Professional Certificate (IBM DAPC)

> **Professional Learning Repository for Data Analytics, Python, SQL, Data Visualization, Artificial Intelligence, and Data Engineering Foundations**

---

## 📖 About This Repository

Welcome to my **IBM Data Analyst Professional Certificate (IBM DAPC)** repository.

This repository documents my complete learning journey through the **IBM Data Analyst Professional Certificate**, offered by **IBM Skills Network** on **Coursera**.

Rather than simply completing the course exercises, this repository is being developed as a **professional GitHub portfolio** that demonstrates practical implementation, structured learning, coding standards, documentation, version control, and continuous improvement.

Every practical exercise is recreated using **Visual Studio Code**, enhanced with additional practice, challenge exercises, debugging notes, and real-world examples.

The long-term goal is to build a comprehensive reference repository for Data Analytics while developing industry-ready skills in Python, SQL, Data Visualization, APIs, Data Engineering foundations, and Artificial Intelligence.

---

## 🎯 Repository Objectives

The objectives of this repository are to:

- Complete all eleven courses in the IBM Data Analyst Professional Certificate.
- Build strong Python programming skills through hands-on practice.
- Develop practical Data Analytics and Business Intelligence skills.
- Learn professional Git and GitHub workflows.
- Build portfolio-quality projects.
- Follow software engineering best practices.
- Strengthen problem-solving and debugging skills.
- Prepare for technical interviews.
- Build a foundation for Data Engineering and Artificial Intelligence.

## 📚 Learning Methodology

This repository follows a structured learning approach based on the **IGLS Method**.

```text
Explain
      ↓
Show
      ↓
Do
      ↓
Fix
      ↓
Master
```

Each concept is first understood, then implemented manually, tested, improved, documented and committed to GitHub.

The objective is not only to complete the IBM course exercises but to develop the confidence to solve real-world problems independently.

## 🧪 Debugging Philosophy

Errors are treated as learning opportunities.

For every issue encountered, the objective is to understand:

- What happened?
- Why did it happen?
- How can it be fixed?
- How can it be prevented?

Developing debugging skills is considered an essential part of becoming a professional programmer.
