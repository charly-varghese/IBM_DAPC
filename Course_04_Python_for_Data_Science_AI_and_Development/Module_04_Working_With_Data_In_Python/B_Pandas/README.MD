## 📌 Overview

This repository contains my complete hands-on learning journey through **Pandas**, developed as part of the **IBM Data Analyst Professional Certificate (IBM DAPC)**.

The goal of this repository is **not only to complete IBM Practice Labs**, but to build a professional, GitHub-ready Python portfolio demonstrating practical data analysis and software development skills.

Every topic has been implemented, tested, documented, and enhanced using **Visual Studio Code**, following professional coding practices.

## 🎯 Learning Objectives

Throughout this module, I learned how to:

- Create and manipulate DataFrames and Series
- Select rows and columns efficiently
- Use `loc[]` and `iloc[]`
- Slice datasets
- Filter data
- Sort datasets
- Group data
- Perform aggregation
- Handle missing values
- Build data cleaning pipelines
- Integrate multiple datasets
- Generate business reports
- Analyze time series data
- Develop a complete Employee Analytics project
