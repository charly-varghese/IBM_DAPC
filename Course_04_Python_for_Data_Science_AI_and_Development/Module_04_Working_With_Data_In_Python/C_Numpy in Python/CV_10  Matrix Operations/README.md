## Common Mistakes

- Confusing element-wise multiplication with matrix multiplication.
- Attempting matrix multiplication with incompatible dimensions.
- Forgetting that transpose changes rows into columns.
- Assuming `*` performs matrix multiplication.

---

## Key Takeaways

- Matrices organize data into rows and columns.
- Matrix multiplication differs from element-wise multiplication.
- `np.matmul()` is the preferred function for matrix multiplication.
- Identity matrices are widely used in linear algebra.
- Matrix operations are essential for AI, ML, and advanced analytics.

## Quick Revision

``
A + B → Matrix Addition

A - B → Matrix Subtraction

A \* B → Element-wise Multiplication

np.matmul(A, B) → Matrix Multiplication

np.dot(A, B) → Dot Product

A.T → Transpose

np.eye(3) → Identity Matrix
``
