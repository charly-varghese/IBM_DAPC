# CV_06 – Array Operations

## Objective

Learn how to perform arithmetic operations on NumPy arrays using vectorized computations. These operations are fundamental to Data Analytics, Business Intelligence, Financial Analysis, Machine Learning, and AI because they enable fast and efficient processing of large datasets.

---

## Learning Objectives

After completing this module, you will be able to:

- Perform element-wise addition, subtraction, multiplication, and division.
- Apply scalar operations to entire arrays.
- Use vectorized operations instead of loops.
- Perform business calculations efficiently.
- Understand why NumPy is faster than Python lists.

## Key Operations

| Operation | Example | Purpose |
| --------- | ------- | ------- |

| Addition | `arr1 + arr2` | Combine values |
| Subtraction | `arr1 - arr2` | Find differences |
| Multiplication | `arr1 * arr2` | Element-wise multiplication |
| Division | `arr1 / arr2` | Element-wise division |
| Scalar Addition | `arr + 100` | Increase all values |
| Scalar Multiplication | `arr * 5` | Scale all values |
| Exponentiation | `arr ** 2` | Square values |

## Common Mistakes

- Trying to operate on arrays with incompatible shapes.
- Confusing element-wise multiplication with matrix multiplication.
- Dividing by zero.
- Using loops when vectorized operations are available.

---

## Key Takeaways

- NumPy performs operations element by element.
- Vectorization makes NumPy extremely fast.
- Scalar operations apply to every element in an array.
- Array operations simplify business calculations.
- These operations form the foundation for machine learning and data analysis.
