# CV_04 – Array Attributes

## Objective

Learn how to inspect and understand the important attributes of NumPy arrays. These attributes help analyze the structure, size, data type, and memory usage of arrays, making them essential for Data Analytics, Machine Learning, AI, and Data Engineering.

---

## Learning Objectives

After completing this module, you will be able to:

- Understand the structure of NumPy arrays.
- Identify the shape of an array.
- Determine the number of dimensions.
- Calculate the total number of elements.
- Identify the data type of array elements.
- Measure memory consumption.
- Convert data types using `astype()`.

## Key Attributes

| Attribute | Description |
| --------- | ----------- |

| `shape` | Number of rows and columns |
| `ndim` | Number of dimensions |
| `size` | Total number of elements |
| `dtype` | Data type of elements |
| `itemsize` | Memory used by one element |
| `nbytes` | Total memory used |
| `astype()` | Convert data type |

## Common Mistakes

- Confusing `shape` with `size`.
- Assuming `dtype` never changes.
- Forgetting that `astype()` returns a new array.
- Ignoring memory usage when working with large datasets.

---

## Key Takeaways

- Array attributes describe the structure and memory usage of NumPy arrays.
- `shape`, `ndim`, and `size` explain the organization of data.
- `dtype` determines how data is stored.
- `itemsize` and `nbytes` help estimate memory requirements.
- `astype()` is essential for data preparation and machine learning workflows.
