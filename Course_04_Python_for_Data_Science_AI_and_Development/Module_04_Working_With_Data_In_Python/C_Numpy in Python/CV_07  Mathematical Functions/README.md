## Common Mistakes

- Applying `np.log()` to zero or negative values.
- Assuming `round()`, `ceil()`, and `floor()` behave the same.
- Forgetting that `np.exp()` grows very rapidly.
- Ignoring data types after mathematical operations.

---

## Key Takeaways

- NumPy provides efficient mathematical operations for arrays.
- Mathematical functions are vectorized and operate on every element.
- Rounding functions are essential for reporting.
- Logarithmic and exponential functions are frequently used in Machine Learning and statistical modeling.
- These functions simplify complex numerical computations.
