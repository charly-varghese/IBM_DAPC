# CV_09 – Two-Dimensional Arrays

## Objective

Learn how to create, access, and manipulate two-dimensional NumPy arrays. Two-dimensional arrays represent tabular data and form the foundation for working with spreadsheets, databases, CSV files, Pandas DataFrames, and Machine Learning datasets.

---

After completing this module, you will be able to:

- Create two-dimensional NumPy arrays.
- Determine the number of rows and columns.
- Access rows, columns, and individual elements.
- Understand the structure of tabular datasets.
- Apply 2D arrays to business and analytics scenarios.

## Key Operations

| Operation | Example | Purpose |
| --------- | ------- | ------- |

| Create 2D Array | `np.array([[1,2],[3,4]])` | Create tabular data |
| Access Row | `arr[0]` | Retrieve a row |
| Access Column | `arr[:,1]` | Retrieve a column |
| Access Element | `arr[1,2]` | Retrieve a specific value |
| Shape | `arr.shape` | Get rows and columns |

## Common Mistakes

- Confusing row and column indexes.
- Forgetting that indexing starts from zero.
- Mixing one-dimensional and two-dimensional indexing.
- Accessing an index outside the array bounds.

---

## Key Takeaways

- Two-dimensional arrays represent rows and columns.
- Most real-world datasets are naturally two-dimensional.
- Rows typically represent records, while columns represent attributes.
- Efficient row and column access is fundamental to data analysis.
- Mastering 2D arrays prepares you for Pandas and Machine Learning.

arr.ndim → Number of Dimensions
