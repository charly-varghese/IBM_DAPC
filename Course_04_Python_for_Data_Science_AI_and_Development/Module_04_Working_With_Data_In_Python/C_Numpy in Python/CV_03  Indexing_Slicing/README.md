## Key Operations

| Operation | Example | Purpose |
| --------- | ------- | ------- |

| Positive Indexing | `arr[0]` | Access the first element |
| Negative Indexing | `arr[-1]` | Access the last element |
| Basic Slicing | `arr[1:4]` | Extract a range of elements |
| Step Slicing | `arr[::2]` | Select alternate elements |
| Reverse Array | `arr[::-1]` | Reverse the array |
| Update Value | `arr[2] = 100` | Modify an existing value |

## Common Mistakes

- Accessing an index that does not exist.
- Forgetting that the ending index in slicing is excluded.
- Confusing indexing with slicing.
- Using incorrect negative indexes.
- Accidentally modifying the original array when updates are not intended.

## Quick Revision

``
arr[0] → First Element

arr[-1] → Last Element

arr[1:4] → Elements from Index 1 to 3

arr[:3] → First Three Elements

arr[3:] → From Index 3 to End

arr[::2] → Alternate Elements

arr[::-1] → Reverse Array

arr[2]=100 → Update Value
``
