## Key Functions

| Function | Purpose |
| -------- | ------- |

| `np.array()` | Create a NumPy array from a Python list or tuple |
| `np.zeros()` | Create an array filled with zeros |
| `np.ones()` | Create an array filled with ones |
| `np.arange()` | Generate a sequence of evenly spaced numbers |
| `np.random.seed()` | Produce reproducible random numbers |
| `np.random.randint()` | Generate random integers within a specified range |

## Common Mistakes

- Forgetting to import NumPy before creating arrays.
- Confusing `range()` with `np.arange()`.
- Assuming `np.arange()` includes the ending value (it does not).
- Forgetting to set `np.random.seed()` when reproducible results are required.
- Creating arrays with mixed data types unintentionally.

---

## Key Takeaways

- NumPy provides multiple methods for creating arrays efficiently.
- `np.array()` converts Python objects into NumPy arrays.
- `np.zeros()` and `np.ones()` are useful for initializing datasets.
- `np.arange()` quickly generates sequential values.
- `np.random.randint()` is useful for creating sample datasets.
- `np.random.seed()` ensures consistent random values during testing and model development.
- Array creation is the first step in most Data Science and Machine Learning workflows.
