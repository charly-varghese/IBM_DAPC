## Common Mistakes

- Using assignment (`=`) instead of comparison (`==`) in conditions.
- Forgetting to wrap Boolean conditions in square brackets.
- Assuming `np.sort()` modifies the original array.
- Ignoring duplicate values during analysis.

- Unique values help identify duplicates.
