# CV_05 – Statistical Functions

## Objective

Learn how to perform statistical analysis using NumPy. Statistical functions help summarize, analyze, and interpret datasets, making them essential for Data Analytics, Business Intelligence, Machine Learning, AI, and Data Engineering.

- Find the median value.

- Measure data spread using standard deviation and variance.
- Calculate percentiles.
- Apply statistical analysis to business datasets.

## Key Functions

| Function | Purpose |
| -------- | ------- |

| `np.sum()` | Total of all values |
| `np.mean()` | Average value |
| `np.median()` | Middle value |
| `np.min()` | Smallest value |
| `np.max()` | Largest value |
| `np.std()` | Standard deviation |
| `np.var()` | Variance |
| `np.percentile()` | Calculate percentile |

## Common Mistakes

- Confusing mean and median.
- Ignoring outliers when interpreting averages.
- Mixing variance and standard deviation.
- Using percentiles incorrectly.
- Assuming the mean always represents the dataset accurately.

---

## Key Takeaways

- Statistical functions summarize datasets efficiently.
- Mean, median, minimum, and maximum describe central values.
- Standard deviation and variance measure variability.
- Percentiles divide data into meaningful groups.
- Statistical analysis supports informed business decisions.
