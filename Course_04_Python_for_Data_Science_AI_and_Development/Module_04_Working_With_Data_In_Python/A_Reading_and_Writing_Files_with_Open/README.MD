# 📂 Module 04 – Working with Data in Python

## A. Reading & Writing Files

This module is part of the **IBM Data Analyst Professional Certificate (IBM DAPC)**.

The objective of this section is to learn how Python works with text files using built-in file handling functions. The labs cover reading, writing, copying, and processing text files using industry-standard Python practices.

---

## 🎯Learning Objectives

After completing this module, I will be able to:

- Read text files using Python.
- Write data into text files.
- Append data to existing files.
- Copy the contents of one file to another.
- Process file data using loops and conditions.
- Apply Python file handling in real-world data processing tasks.
