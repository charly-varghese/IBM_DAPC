# D. Exception Handling

## 📌 Overview

This module introduces **Exception Handling** in Python, a fundamental programming technique used to detect, handle, and recover from runtime errors without terminating the program unexpectedly.

The IBM Lab demonstrates how to use `try`, `except`, `else`, and `finally` blocks to write robust and reliable Python programs.

---

## 🎯 Learning Objectives

After completing this lab, you will be able to:

- Understand the purpose of exception handling.
- Handle common runtime errors gracefully.
- Prevent program crashes caused by invalid input or unexpected situations.
- Use different exception handling blocks effectively.
- Write more reliable and maintainable Python programs.

## 🧪 IBM Lab Exercises

### Exercise 1 – Handling Division by Zero

Implemented a function to safely divide two numbers while handling the `ZeroDivisionError`.

Example:

```python
safe_divide(10, 2)
safe_divide(10, 0)
```

---

### Exercise 2 – Handling Invalid Numeric Input

Used exception handling to prevent program failure when calculating the square root of an invalid number.

Handled:

- ValueError

Example:

```python
perform_calculation(25)
perform_calculation(-4)
```

---

### Exercise 3 – Generic Exception Handling

Implemented a function demonstrating how to catch unexpected runtime errors using the generic `Exception` class.

Example:

```python
complex_calculation(100, 5)
complex_calculation(100, 0)
```
