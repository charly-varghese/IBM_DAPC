## 🎯 Objective

This lab introduces the fundamentals of looping in Python using **`for`** and **`while`** loops. It demonstrates how to iterate through sequences, process lists, control loop execution, and use loop control statements such as **`break`** and **`continue`**.

---

## 📖 Topics Covered

- `for` loop
- `while` loop
- `range()` function
- List iteration
- List indexing
- `len()` function
- `break` statement
- `continue` statement
- List operations using `append()`

---

## 📝 Exercises Completed

### Exercise 1

Print numbers from **-5 to 5** using the `range()` function and a `for` loop.

---

### Exercise 2

Iterate through a list of music genres and print each genre.

**Dataset:**

```python
Genres = ['rock', 'R&B', 'Soundtrack', 'R&B', 'soul', 'pop']
```

---

### Exercise 3

Iterate through a list of colours and print each element.

**Dataset:**

```python
squares = ['red', 'yellow', 'green', 'purple', 'blue']
```

---

### Exercise 4

Use a `while` loop to display playlist ratings.

The loop terminates when a rating is less than **6**.

**Dataset:**

```python
PlayListRatings = [10, 9.5, 10, 8, 7.5, 5, 10, 10]
```

---

### Exercise 5

Copy consecutive `"orange"` values from one list into another using a `while` loop.

The loop stops immediately when a different colour is encountered.

**Dataset:**

```python
squares = ['orange', 'orange', 'purple', 'blue', 'orange']
```

---

### Exercise 6

Print numbers from **1 to 15** using a `for` loop while:

- Skipping multiples of **3** using `continue`
- Stopping the loop when the number becomes greater than **12** using `break`
