## 📚 Module

**Course 04:** Python for Data Science, AI & Development

---

## 🎯 Objective

This lab introduces the fundamentals of decision-making in Python using conditional statements and logical operators. It demonstrates how to evaluate conditions, filter records, and display information based on specific criteria.

---

## 📖 Topics Covered

- `if` statement
- Nested `if` statement
- Comparison Operators (`>`, `<`, `==`, `!=`)
- Logical Operators (`and`, `or`)
- `for` loop with dictionaries
- Accessing dictionary values using keys

---

## 📂 Dataset

The lab uses a sample dataset of athletes represented as a list of dictionaries.

Each record contains:

- Player Name
- Sport
- Achievements

Example:

```python
{
    "name": "Lionel Messi",
    "sport": "Soccer",
    "achievements": 7
}
```

---

## 📝 Exercises Completed

### Exercise 1

Check whether **Lionel Messi** has more than **10 achievements**.

- If True → Display player details.
- Otherwise → Display an appropriate message.

---

### Exercise 2

Display players who:

- Play **Tennis**
- **OR**
- Have exactly **20 achievements**

---

### Exercise 3

Display players who:

- Have **less than 10 achievements**
- **AND**
- Do **not** play Soccer.
