# E. Objects and Classes

## 📌 Overview

This module introduces the fundamentals of **Object-Oriented Programming (OOP)** in Python. It demonstrates how to create classes and objects, define attributes and methods, and apply encapsulation to model real-world entities.

The IBM Lab includes practical implementations using **Circle**, **Rectangle**, and **Vehicle** classes, providing hands-on experience with constructors, object creation, instance methods, and object manipulation.

---

## 🎯 Learning Objectives

After completing this lab, you will be able to:

- Understand Object-Oriented Programming (OOP) concepts.
- Create Python classes and instantiate objects.
- Define and initialize object attributes using constructors.
- Create and call instance methods.
- Modify object properties dynamically.
- Model real-world entities using classes.
- Improve code organization and reusability.

## 🧪 IBM Lab Exercises

### Exercise 1 – Circle Class

Implemented a `Circle` class with:

- Radius
- Color
- Constructor
- Drawing Method
- Updating Radius

Example:

```python
RedCircle = Circle(5, "red")
BlueCircle = Circle(10, "blue")
```

---

### Exercise 2 – Rectangle Class

Implemented a `Rectangle` class with:

- Width
- Height
- Color
- Area Representation

Example:

```python
SkinnyBlueRectangle = Rectangle(2, 10, "Blue")
FatYellowRectangle = Rectangle(20, 5, "Yellow")
```

---

### Exercise 3 – Vehicle Class

Designed a `Vehicle` class containing:

- Vehicle Type
- Maximum Speed
- Mileage
- Seating Capacity
- Color
- Display Method

Example:

```python
Vehicle1 = Vehicle("Car", 180, 5, 5)
Vehicle2 = Vehicle("Bus", 120, 8, 50)
```
