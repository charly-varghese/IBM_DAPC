## 🎯 Objective

This lab introduces the concept of **functions** in Python. It demonstrates how to create reusable blocks of code, pass arguments to functions, return values, use default parameters, understand variable scope, and work with variable-length arguments.

---

## 📖 Topics Covered

- Function definition using `def`
- Function parameters
- Return values using `return`
- Function calls
- Default argument values
- Global variables
- Local variables
- Variable scope
- `*args`
- `**kwargs`
- String processing using functions

---

## 📝 Exercises Completed

### Exercise 1

Create a function to divide the first input by the second input.

---

### Exercise 2

Create and use the `con()` function to add two values.

```python
def con(a, b):
    return a + b
```

---

### Exercise 3

Verify that the `con()` function can be used with:

- Integers
- Strings

---

### Exercise 4

Verify that the `con()` function can concatenate:

- Lists
- Tuples

---

### Exercise 5

Write a function to count the total occurrences of the word **"little"** in a given string.
